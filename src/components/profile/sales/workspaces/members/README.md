# Miembros del espacio

Modal desde **Espacios → Gestionar miembros**. Sirve para decidir quién ve y trabaja en ese espacio, no para administrar toda la empresa.

## Cómo se presenta

Dos pestañas, no un formulario y tres listas a la vez:

1. **Miembros** — quién está en el espacio (quitar / editar) y un directorio buscable de la empresa con **Agregar** / **En el espacio**. Crear usuario y la página completa son acciones secundarias.
2. **Crear usuario** (o **Editar usuario**) — alta de `user_company`. Al crear, queda marcado para el espacio; hay que confirmar con **Guardar miembros**.

En móvil es hoja inferior; en `sm+`, modal centrado. Pie fijo con conteo y guardar.
